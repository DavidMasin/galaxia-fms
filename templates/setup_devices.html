Adding a device
  1. Flash a board with an example sketch, or click Add device to get a token and a snippet first.
  2. It appears at the top, waiting for approval. Click Approve.
  3. On the Bindings page, say what its inputs do.
  4. Trigger the sensor: its value flashes here, and the score changes in a match.

Add device

The FMS makes a token for the device. Put it in the firmware, and the device is let in as soon as it connects: no approval needed.

Lowercase letters, digits and dashes. The firmware uses the same id.

Token

This token is shown once. Copy it, or a snippet with it, now: the FMS keeps only a fingerprint of it. A lost token is replaced with More > New token.
