Webhooks

A webhook sends what happens on the field to a program of yours, as an HTTP POST for each event: a stream overlay, a scoreboard, a chat bot. Each POST is signed with the webhook's secret, so the program can tell it really came from this FMS. A delivery that fails is tried again for 24 hours. How to receive and verify one is in docs/webhooks.md.
